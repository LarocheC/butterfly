# Phase 1, Plan 1: pyproject.toml and Build Shim

## Objective

Create pyproject.toml with PEP 621 metadata and build-system declaration, reduce setup.py to a thin extension-only shim, fix CUDA architecture flags, add MANIFEST.in, and delete stale requirements.txt.

## Context

- @.planning/phases/01-build-system-foundation/01-CONTEXT.md
- @.planning/research/ARCHITECTURE.md
- @.planning/research/PITFALLS.md
- @setup.py (current build script)

## Tasks

### Task 1: Create pyproject.toml
type="auto"

Create `pyproject.toml` with:
- `[build-system]` declaring setuptools>=77, torch>=2.0, ninja, wheel
- `[project]` with PEP 621 metadata (name, version, description, readme, license, requires-python>=3.10, authors, keywords)
- `dependencies = ["torch>=2.0", "numpy"]`
- `[project.optional-dependencies]` with dev and test groups
- `[tool.setuptools.packages.find]` with `include = ["torch_butterfly*"]`

Done: pyproject.toml exists with all required sections.

### Task 2: Reduce setup.py to thin shim
type="auto"

Strip all metadata from setup.py. Keep only:
- `get_extensions()` function with CUDA detection
- `setup(ext_modules=..., cmdclass=...)` call
- Fix CUDA architecture: remove `-arch=sm_35`, use TORCH_CUDA_ARCH_LIST env var with default `7.0 8.0 9.0+PTX`
- Add `-O3` to C++ compile args
- Keep FORCE_CUDA, FORCE_CPU, BUILD_DOCS, NVCC_FLAGS env vars
- Keep `no_python_abi_suffix=True` for now (Phase 2 will address)

Done: setup.py contains only extension logic, no metadata.

### Task 3: Create MANIFEST.in
type="auto"

Create MANIFEST.in to include csrc/ sources in sdist:
- `recursive-include csrc *.cpp *.cu *.h *.cuh`
- Include LICENSE, README.md

Done: MANIFEST.in exists.

### Task 4: Delete requirements.txt
type="auto"

Delete the stale requirements.txt (python>=3.6, pytorch>=1.8, ray>=0.6.5, numpy). pyproject.toml is now the single source of truth.

Done: requirements.txt no longer exists.

## Verification

- [ ] pyproject.toml is valid TOML with all required sections
