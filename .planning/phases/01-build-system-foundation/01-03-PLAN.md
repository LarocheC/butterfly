  <action>
Run two install tests in isolated virtual environments. The goal is to verify the build pipeline works, not that CUDA extensions compile (CUDA toolkit may not be available on the build machine).

**Test 1: uv pip install . (INST-01)**
```bash
# Create fresh venv and install
uv venv /tmp/test-butterfly-uv --python 3.12
VIRTUAL_ENV=/tmp/test-butterfly-uv uv pip install . --no-build-isolation 2>&1
# Verify import works
/tmp/test-butterfly-uv/bin/python -c "import torch_butterfly; print('OK:', torch_butterfly.__file__)"
# Cleanup
rm -rf /tmp/test-butterfly-uv
```

Note: Use `--no-build-isolation` if torch is not available via standard PyPI index (build isolation would need torch). If `--no-build-isolation` is needed, that is acceptable -- the important thing is that the pyproject.toml + setup.py combo works with uv.

If torch is not installed, try with FORCE_CPU=1:
```bash
FORCE_CPU=1 uv pip install . --no-build-isolation
```

**Test 2: pip install . (INST-02)**
```bash
python3 -m venv /tmp/test-butterfly-pip
/tmp/test-butterfly-pip/bin/pip install . --no-build-isolation 2>&1
/tmp/test-butterfly-pip/bin/python -c "import torch_butterfly; print('OK:', torch_butterfly.__file__)"
rm -rf /tmp/test-butterfly-pip
```

**Fallback strategy:** If neither uv nor pip can install due to missing torch in the environment:
1. First try: Install torch first, then install torch_butterfly with --no-build-isolation
2. Second try: Use build isolation (may get CPU-only torch, that is OK per Pitfall #1)
3. Last resort: Verify the build configuration is correct by running `python setup.py build_ext --inplace` with FORCE_CPU=1 after manually ensuring torch is available

**What counts as success:**
- The `pip install .` or `uv pip install .` command exits 0
- `import torch_butterfly` does not raise ImportError for the package itself (extension loading errors are expected if CUDA is not available and are Phase 2 scope)
- No conda was used at any step (INST-04)

**What counts as failure requiring plan fixes:**
- pyproject.toml parse errors
- setup.py import errors (other than torch not found in non-isolated env)
- Package not found after install (torch_butterfly not in site-packages)
- Metadata errors (bad requires-python, invalid classifiers, etc.)

If failures occur, diagnose and fix the issue in pyproject.toml, setup.py, or MANIFEST.in before proceeding to the checkpoint.
